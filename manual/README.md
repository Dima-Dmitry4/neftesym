# Методичка «Нефтяша: разработка месторождения на симуляторе»

Интерактивное учебное пособие к игре на [Quarto](https://quarto.org): теория (от пласта и закона Дарси до схемы IMPES,
Писмана, узлового анализа ЭЦН, ГДИС и ЧДД), устройство игры и шесть разборов разработки объектов с расчётами на
**настоящем ядре игры** прямо в браузере.

- **Онлайн:** <https://dmitryvoronin.gitverse.site/neftesim_neftyasha/manual/>
- **PDF:** <https://dmitryvoronin.gitverse.site/neftesim_neftyasha/manual/book/neftyasha-manual.pdf> (кнопка «Скачать PDF»
  в боковой панели книги)
- **На своём компьютере:** двойной щелчок по `открыть-методичку.bat` – запустит локальный сервер (нужен Python) и откроет
  книгу в браузере. Просто открыть `book/index.html` с диска нельзя: виджеты и живые ячейки не работают через `file://`.

## Сборка

Нужны Quarto ≥ 1.7 (PDF собирается встроенным Typst, LaTeX не нужен), Node.js ≥ 22 и Chrome или Edge.

```bash
cd manual
quarto preview                # просмотр с автообновлением
quarto render --to html       # 1. HTML-версия
node tools/freeze.mjs         # 2. «заморозка» интерактива для PDF
quarto render                 # 3. HTML и PDF – в manual/book
```

Шаг 2 открывает каждую главу в Chrome без окна, ждёт окончания расчётов, запускает все живые ячейки и сохраняет
результаты картинками в `images/frozen/<глава>/`. При сборке PDF фильтр `tools/pdf-freeze.lua` ставит их на место
виджетов. Повторять шаг 2 нужно, когда менялись виджеты, живые ячейки или ядро игры; `node tools/freeze.mjs 04-numerics`
переснимет одну главу.

Собранная книга `book/` хранится в репозитории – её раздают Pages; `manual/index.html` (его пишет `tools/redirect.mjs` после
каждой сборки) перенаправляет на неё.

## Как устроено

| Файл | Что делает |
|---|---|
| `tools/sync-core.mjs` | перед каждым рендером вырезает `#sim-core` и `#wasm-accel` из `../index.html` в `assets/js/` и копирует снимки `docs/img` – пособие всегда считает той же версией ядра, что игра |
| `assets/js/neft.js` | помощники для примеров: объект, бурение, расчёт по годам, карты и графики (Observable Plot), сравнение вариантов |
| `assets/js/live.js` | «живые» ячейки: `::: {.live-py}` – Python в браузере (Pyodide), `::: {.live-js}` – JavaScript с ядром игры |
| `assets/py/minisim.py` | учебный двухфазный симулятор на numpy с формулами ядра (карта давления с разломом и т. п.) |
| `_neft.qmd` | подключение ядра в OJS-ячейках главы |
| `tools/freeze.mjs` | снимки виджетов и живых ячеек для PDF (Chrome по протоколу DevTools, без сторонних пакетов) |
| `tools/pdf-freeze.lua` | фильтр PDF-сборки: OJS-ячейки → снимки, у живых ячеек код + результат |

Библиотеки Observable Plot и Pyodide загружаются читателем из CDN (jsdelivr), поэтому для страниц нужен интернет.

## Находка при подготовке (исправлено)

Проверка пересечения граней с разломом в ядре (`segCross`) была строгой, и у «запечатанного» разлома F-1 канонических
объектов оставались щели (строки сетки 2, 10, 14, 22, 30 или 19, 27, 35, 39, 47). В игре это исправлено, эталоны
пересчитаны; подробно – в главе 4, врезка «Находка». `neft.field({ strictGaps: true })` воспроизводит старое поведение.
