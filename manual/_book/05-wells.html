5  Скважины, заканчивание и оборудование

Скважина – единственный способ «дотянуться» до пласта. В игре от неё зависит почти всё: сколько нефти придёт, сколько денег уйдёт на бурение и электроэнергию. В этой главе – как скважина устроена в модели (формула Писмана), какие бывают заканчивания (ВС, ГРП, ГС, МГРП, ЗБС) и как оборудование (штуцер, ЭЦН, КНС) задаёт режим работы.

5.1 Скважина в ячейке: формула Писмана

Скважина диаметром 20 см гораздо меньше ячейки 40×40 м. Давление в ячейке P_{яч} – это не давление у стенки скважины, а некое среднее. Питер Писман (1978) показал, что для пятиточечной схемы давление ячейки совпадает с аналитическим радиальным давлением на расстоянии r_e\approx0{,}2\,\Delta от скважины. Отсюда приток по Дюпюи (2.2):

q = WI\cdot\lambda_t\cdot(P_{яч}-P_{wf}),\qquad WI = K_Д\,\frac{2\pi\,k\,h}{\ln(r_e/r_w)+s},\qquad r_e = 0{,}2\,\Delta,\ r_w=0{,}1\ \text{м}. \tag{5.1}

Нефть и вода делятся по подвижностям ячейки: q_o = q\,(k_{ro}/\mu_o)/\lambda_t, q_w = q\,(k_{rw}/\mu_w)/\lambda_t. Знак клампится: добывающая не может нагнетать, нагнетательная – отбирать.

Именно потому, что r_e пропорционален шагу сетки, продуктивность вертикальной скважины в игре не зависит от выбранной сетки (5,40 м³/сут/атм на сетках 25, 50 и 100 – проверяется самотестом).

5.2 Скин-фактор

Скин s – дополнительное сопротивление у ствола: загрязнение призабойной зоны буровым раствором (s>0) или, наоборот, улучшение после обработки (s<0). У каждой скважины в игре скрытый скин s\in[-1;7]. Узнать его можно ГДИС (Глава 6), снизить до −1 – обработкой призабойной зоны (ОПЗ), 2 млн руб.

viewof sk = Inputs.range([-2, 10], {value: 5, step: 0.5, label: "скин s"})
{
  const B = Math.log(0.2 * 40 / 0.1), J = (s) => 1 / Math.max(0.5, B + s);
  return html`<div class="neft-kpi"><div><b>${(100 * J(sk) / J(0)).toFixed(0)} %</b><span>продуктивность относительно s = 0</span></div>
    <div><b>×${(J(-1) / J(sk)).toFixed(2)}</b><span>прирост дебита после ОПЗ (s → −1)</span></div>
    <div><b>${B.toFixed(2)}</b><span>ln(re/rw) на сетке 40 м</span></div></div>`;
}
СоветКогда делать ОПЗ

При s=7 скважина теряет почти половину дебита, ОПЗ возвращает его за 2 млн руб – окупается за дни. При s=1 прирост около 20 % – тоже обычно выгодно на хорошей скважине. Но вслепую делать ОПЗ не стоит: сначала ГДИС (1 млн руб + недобор за время остановки), потом решение. Эталоны игры на БВ8 и бобриковском так и делают: «ОПЗ после ГДИС».

5.3 Заканчивание: ВС, ГРП, ГС, МГРП, ЗБС

В модели скважина – это набор перфорированных ячеек \{(c, f)\}: приток каждой считается по Писману, множитель f – доля вскрытия ячейки. Разные заканчивания – разные наборы ячеек:

Заканчивание Модель Стоимость (по умолчанию)
ВС – вертикальная одна ячейка, f=1 скважина объекта (40–95 млн руб)
ВС + ГРП трещина полудлиной x_f = 40/80/120 м: ряд ячеек, f подобран под аналитику Cinco-Ley; трещина останавливается на разломах + 20 / 32 / 48 млн руб
ГС – горизонтальная ряд ячеек вдоль ствола длиной L (любой азимут), f=0{,}4\cdot\ell/40 м (согласовано с Джоши при k_v/k_h\approx0{,}1) скважина × (1,2 + 0,5·L/1000)
ГС + МГРП ствол + n поперечных трещин; к скину каждой добавлен скин стягивания к стволу + ГРП(xf) × (0,4 + 0,6·n)
ЗБС – боковой ствол новый ствол из существующей ВС; старый интервал можно изолировать скважина × (0,35 + 0,5·L/1000)

5.3.1 Трещина ГРП: безразмерная проводимость

Эффект ГРП определяет безразмерная проводимость трещины

F_{CD}=\frac{k_f w}{k\,x_f},\qquad k_f w = 1000\ \text{мД·м в игре}.

Если пласт хороший (k велико), F_{CD} мало: трещина не успевает «подвести» нефть, она работает как короткая. Эквивалентный скин трещины (аппроксимация Cinco-Ley–Samaniego): s_f = F(\ln F_{CD})-\ln(x_f/r_w). Прирост продуктивности одной скважины в квадрате 2×2 км:

\frac{J_{ГРП}}{J_{ВС}}=\frac{B}{B+s_f},\qquad B = 8{,}59 . 

viewof fk = Inputs.range([0.01, 1500], {value: 20, label: "k пласта, мД", transform: Math.log})
viewof fxf = Inputs.radio([40, 80, 120], {value: 80, label: "полудлина xf, м"})
{
  const P = neft.Plot, c = neft.colors(), pts = [];
  for (let lk = -2; lk <= 3.2; lk += 0.02) {
    const k = 10 ** lk;
    for (const xf of [40, 80, 120]) { const fcd = 1000 / (k * xf), sf = core.fracSkin(fcd, xf); pts.push({ k, xf: `xf = ${xf} м`, ratio: 8.59 / (8.59 + sf) }); }
  }
  const fcd = 1000 / (fk * fxf), sf = core.fracSkin(fcd, fxf), ratio = 8.59 / (8.59 + sf);
  return html`<div class="neft-kpi"><div><b>${fcd < 10 ? fcd.toFixed(2) : fcd.toFixed(0)}</b><span>FCD</span></div><div><b>${sf.toFixed(2)}</b><span>скин трещины sf</span></div>
    <div><b>×${ratio.toFixed(2)}</b><span>прирост продуктивности</span></div></div>
    ${P.plot({ width: 640, height: 260, marginLeft: 48, x: { type: "log", label: "k пласта, мД", grid: true }, y: { label: "J_ГРП / J_ВС", grid: true },
      color: { domain: ["xf = 40 м", "xf = 80 м", "xf = 120 м"], range: c.s.slice(0, 3), legend: true },
      marks: [P.line(pts, { x: "k", y: "ratio", stroke: "xf", strokeWidth: 2 }), P.dot([[fk, ratio]], { r: 6, fill: c.ink }),
              P.tip(pts, P.pointer({ x: "k", y: "ratio", stroke: "xf", title: (d) => `${d.xf}\nk = ${d.k.toPrecision(3)} мД\n×${d.ratio.toFixed(2)}` }))] })}`;
}

Вывод прямо с графика: в русле 500–1000 мД ГРП почти бесполезен (×1,1–1,3, а стоит как треть скважины), при 10–20 мД даёт ×2–2,5, а при долях миллидарси – ×3 и больше. Удлинять трещину имеет смысл только при высокой F_{CD}, то есть в плохом пласте.

5.3.2 Горизонтальные скважины и МГРП

ГС вскрывает пласт на длине L, приток растёт почти пропорционально длине (сверено с формулой Джоши: ГС 200/400/600 м даёт ×2,0/3,1/4,0 к ВС). МГРП – несколько поперечных трещин вдоль ГС. Каждая трещина получает дополнительный скин стягивания – поток в плоскости трещины сходится к стволу радиально:

s_c=\frac{k\,h}{k_f w}\left(\ln\frac{h}{2r_w}-\frac{\pi}{2}\right).

Трещины мешают друг другу (интерференция), поэтому отдача от каждой следующей стадии убывает. В самотесте при k=20 мД ГС 1000 м с 3/6/12 стадиями даёт ×1,14/1,26/1,39 к самой ГС, а при k=100 мД шесть стадий – лишь ×1,04.

Важное уведомлениеПравило выбора заканчивания
Проницаемость Что работает
> 200 мД (БВ8, бобриковский) ВС; ГРП и МГРП не окупаются
10–100 мД (ЮВ1, АВ1, купол) ВС + ГРП 80–120 м или ГС
< 5 мД (матрица ЮК10–11) ГРП обязательно
< 0,5 мД (ачимовка) только ГС + МГРП с большим числом стадий

Проверьте это на ядре игры в разборе Глава 11.

5.4 Оборудование и узловой анализ

В игре нельзя «просто задать» забойное давление. Его определяет равновесие пласта и подъёмника: пласт отдаёт тем больше, чем ниже P_{wf} (линия притока, IPR), а подъёмник может поднять тем больше, чем выше P_{wf}. Рабочая точка – их пересечение. Так работает функция solveEquipment ядра (бисекция по дебиту).

  • Фонтан (штуцер): P_{wf}=P_{сбор}+\Delta P_{шт}(q)+\rho g H, \Delta P_{шт}=\rho v^2/2, v=q/(C_dA), C_d=0{,}8. Когда пластовое давление падает ниже столба жидкости, фонтан глохнет – нужен ЭЦН.
  • ЭЦН: P_{wf}=P_{сбор}+\rho g H-\rho g\,H_{ЭЦН}(q,f), напор по законам подобия H=H_0\,(f/50)^2\left[1-\left(\frac{q}{Q_0\,f/50}\right)^2\right], мощность N=\rho g q H/\eta (электроэнергия 5,5 руб/кВт·ч). Давление на приёме не ниже 20 атм.
  • Нагнетательная (КНС): P_{wf}=P_{КНС}-\Delta P_{шт}(q)+\rho_в g H, но не выше предела ≈ 0,14 атм/м глубины (давление гидроразрыва).

Подберите насос сами. По умолчанию – пласт 220 атм, глубина 2400 м, продуктивность 3 м³/сут/атм:

viewof nod = Inputs.form({
  Pr: Inputs.range([80, 330], { value: 220, step: 1, label: "Пластовое давление, атм" }),
  J: Inputs.range([0.1, 30], { value: 3, step: 0.1, label: "Продуктивность J, м³/сут/атм" }),
  H: Inputs.range([1200, 2900], { value: 2400, step: 10, label: "Глубина, м" }),
  fw: Inputs.range([0, 0.98], { value: 0.3, step: 0.01, label: "Обводнённость" }),
  pump: Inputs.select(core.PUMP_NOMINALS.map(String), { value: "250", label: "Типоразмер ЭЦН" }),
  f: Inputs.range([30, 60], { value: 50, step: 1, label: "Частота, Гц" }),
  pg: Inputs.range([5, 20], { value: 12, step: 1, label: "Давление сбора, атм" }),
})
Код: рабочая точка ЭЦН (те же функции ядра, что в игре) 
nodal = {
  const { Pr, J, H, fw, pump, f, pg } = nod, rho = 860 * (1 - fw) + 1000 * fw, g = 9.81, ATM = 101325;
  const ipr = (q) => Pr - q / J;                                             // пласт: Pwf, при котором он отдаёт q
  const lift = (q) => pg + rho * g * H / ATM - rho * g * Math.max(0, core.espHeadM(q, f, pump)) / ATM; // насос: нужное Pwf
  const qMax = J * (Pr - 20);                                                // приём не ниже 20 атм
  let a = 0, b = qMax;
  if (ipr(0) - lift(0) <= 0) a = b = 0;
  else if (ipr(qMax) - lift(qMax) >= 0) a = b = qMax;
  else for (let n = 0; n < 60; n++) { const m = (a + b) / 2; if (ipr(m) - lift(m) > 0) a = m; else b = m; }
  const q = (a + b) / 2, P = core.PUMPS[pump];
  const curve = [];
  for (let x = 0; x <= Math.max(qMax, P.Q0 * f / 50) * 1.02; x += Math.max(0.5, qMax / 300)) curve.push({ q: x, ipr: ipr(x), lift: lift(x) });
  return { q, pwf: ipr(q), kW: q > 0 ? core.espPowerKW(q, f, rho, pump) : 0, load: q / (P.QB * f / 50), eff: core.espEff(q, f, pump), curve, capped: q >= qMax - 1e-6 && qMax > 0 };
}
{
  const P = neft.Plot, c = neft.colors(), n = nodal, lo = n.load < 0.6, hi = n.load > 1.2;
  const verdict = n.q === 0 ? "насос не поднимает жидкость – нужен больший напор (типоразмер/частота) или выше пластовое давление"
    : n.capped ? "отбор упёрся в минимальное давление на приёме (20 атм) – пласт отдаёт всё, что может; больше даст только ППД"
    : lo ? "насос велик: загрузка < 60 %, низкий КПД – возьмите типоразмер меньше или снизьте частоту"
    : hi ? "перегруз: загрузка > 120 % – нужен больший типоразмер" : "насос работает в оптимальной зоне 60–120 %";
  const data = n.curve.flatMap((d) => [{ q: d.q, P: d.ipr, s: "приток пласта (IPR)" }, { q: d.q, P: d.lift, s: "ЭЦН: требуемое Pwf" }]);
  return html`<div class="neft-kpi"><div><b>${n.q.toFixed(0)} м³/сут</b><span>дебит жидкости</span></div><div><b>${n.pwf.toFixed(0)} атм</b><span>забойное давление</span></div>
    <div><b>${(100 * n.load).toFixed(0)} %</b><span>загрузка насоса</span></div><div><b>${(100 * n.eff).toFixed(0)} %</b><span>КПД</span></div>
    <div><b>${n.kW.toFixed(0)} кВт</b><span>мощность, ≈ ${(n.kW * 24 * 365 * 5.5 / 1e6).toFixed(1)} млн руб/год</span></div></div>
    <p><b>Вывод:</b> ${verdict}.</p>
    ${P.plot({ width: 640, height: 300, marginLeft: 50, x: { label: "дебит жидкости q, м³/сут", grid: true }, y: { label: "Pwf, атм", grid: true, domain: [0, Math.max(nod.Pr, 50) + 20] },
      color: { domain: ["приток пласта (IPR)", "ЭЦН: требуемое Pwf"], range: [c.s[1], c.s[0]], legend: true },
      marks: [P.line(data, { x: "q", y: "P", stroke: "s", strokeWidth: 2 }), P.ruleY([20], { stroke: c.muted, strokeDasharray: "4,3" }),
              P.dot([[n.q, n.pwf]], { r: 7, fill: c.ink, symbol: "star" }),
              P.tip(data, P.pointer({ x: "q", y: "P", stroke: "s", title: (d) => `${d.s}\nq = ${d.q.toFixed(0)}\nPwf = ${d.P.toFixed(1)} атм` }))] })}`;
}

Опыты:

  1. Обводнённость 0 → 0,9: столб тяжелее, рабочая точка сдвигается – насосу труднее.
  2. Пластовое давление 220 → 150 атм (нет закачки): дебит падает сильнее, чем пропорционально.
  3. Большой насос (ЭЦН-800) на скважине с J=1: загрузка мала, КПД низкий, деньги на электроэнергию уходят зря.
УведомлениеЭто упрощённый перенос модулей unfpy

Модель оборудования игры – упрощённая версия расчётов из соседней Python-библиотеки unfpy (ЭЦН по законам подобия, штуцер, гидростатика). Свободный газ, температура и многофазные корреляции не учитываются.

5.5 Нагнетательные скважины и ППД

Нагнетательная – та же скважина, но с обратным знаком потока. Закачку задают давление КНС (общее для поля) и штуцер каждой скважины. Электроэнергия КНС: E = P_{КНС}\,V/\eta, \eta=0{,}7 – около 5 кВт·ч на м³ при 130 атм.

В игре любую добывающую можно перевести под закачку (💧→, 5 млн руб) и обратно. Типичный приём эталонов: бурить скважины как добывающие, год-два отбирать нефть (пока у неё нет воды), затем переводить часть под закачку – так нагнетательные успевают окупиться нефтью.

5.6 Вопросы и задания

  1. Почему r_e в формуле Писмана пропорционален шагу сетки, а не расстоянию до соседних скважин?
  2. При каком k трещина 120 м даёт тот же прирост, что 40 м? Объясните через F_{CD}.
  3. В узловом анализе найдите минимальную частоту ЭЦН-250, при которой скважина с J=3 ещё работает при 150 атм.
  4. Сколько стоит в год электроэнергия ЭЦН мощностью 100 кВт? Сравните с ценой 1 т нефти.
