10  Разбор 1. БВ8: зачем нужна закачка

neft = {
  const m = await import(new URL("assets/js/neft.js", document.baseURI).href);
  await m.ready();
  return m;
}
core = neft.core()

БВ8 (вартовская свита, Самотлор) – «классический» высокопроницаемый объект: медиана 250 мД, русла до 1200 мД, лёгкая нефть 1,4 сП, неглубоко (≈ 2100 м), скважина 70 млн руб. Сложность ★. Здесь хорошо видны три главных урока игры: без закачки нет разработки, лишние скважины не окупаются и насос решает.

10.1 Постановка опыта

Пять вариантов на каноническом объекте (сид 0), 5 лет, одинаковые цены. Все добывающие – вертикальные на ЭЦН, нагнетательные – КНС 130 атм, штуцер 16 мм.

Вариант Скважины
A. Без ППД 3 добывающие в своде, ЭЦН-250
B. 3 + 2 те же 3 добывающие + 2 нагнетательные на западе зоны
C. Редко, 2 + 1 2 добывающие + 1 нагнетательная
D. Густо, 9 + 4 сетка 250 м, 13 скважин
E. 3 + 2, ЭЦН-800 как B, но насосы крупнее 
viewof go11 = Inputs.button("▶ Рассчитать варианты")
viewof layer11 = Inputs.radio(new Map([["насыщенность", "Sw"], ["давление", "P"]]), { label: "Карты", value: "Sw" })
Код вариантов (ядро игры) 
variants11 = {
  const three = (f, pump = "250") => [[750, 1000], [1000, 1150], [1000, 800]].forEach(([x, y]) => f.drill({ x, y, pump }));
  const inj = (f, pts) => pts.forEach(([x, y]) => f.drill({ x, y, type: "inj", choke: 16 }));
  const F = () => neft.field({ scenario: "bv8" });
  return [
    ["A. Без ППД", () => { const f = F(); three(f); return f; }],
    ["B. 3 + 2", () => { const f = F(); three(f); inj(f, [[700, 1300], [700, 650]]); return f; }],
    ["C. Редко, 2 + 1", () => { const f = F(); f.drill({ x: 900, y: 1200 }); f.drill({ x: 900, y: 700 }); inj(f, [[650, 950]]); return f; }],
    ["D. Густо, 9 + 4", () => { const f = F(); for (const x of [600, 850, 1100]) for (const y of [700, 950, 1200]) f.drill({ x, y });
                                inj(f, [[725, 825], [975, 825], [725, 1075], [975, 1075]]); return f; }],
    ["E. 3 + 2, ЭЦН-800", () => { const f = F(); three(f, "800"); inj(f, [[700, 1300], [700, 650]]); return f; }],
  ];
}
run11 = {
  if (!go11) { yield null; return; }
  for await (const st of neft.compare(variants11, 5, { step: 60 })) yield st;
}
neft.report(run11, { layer: layer11, mapWidth: 260 })

10.2 Что получилось и почему

Ожидаемые результаты за 5 лет (так считает ядро версии 0.12.1):

Вариант КИН ЧДД, млрд руб Ср. давление, атм
A. Без ППД 4 % 0,9 102 (у скважин – 20)
B. 3 + 2 22 % 4,5 255
C. Редко, 2 + 1 17 % 3,6 252
D. Густо, 9 + 4 20 % 3,1 254
E. 3 + 2, ЭЦН-800 27 % 5,6 236

A → B: закачка. Без ППД давление в блоке со скважинами уже к концу первого года падает с 211 атм почти до 20 атм – минимального давления на приёме ЭЦН. Скважины фактически встают (на графике добычи вариант A обрывается около 1 года), добыто 4 % запасов. Всего две нагнетательные увеличивают КИН и ЧДД в пять раз. Это главный урок игры.

Восточный блок не тронут. Среднее давление варианта A – 102 атм, а не 20: восточный блок за запечатанным разломом F-1 не связан со скважинами и во всех пяти вариантах держит начальные 211 атм (посмотрите на карту давления). Его запасы входят в знаменатель КИН, поэтому КИН здесь скромнее, чем мог бы быть. Чтобы их взять, нужны своя добывающая и своя нагнетательная за разломом (Глава 12).

B → D: густая сетка хуже. 13 скважин вместо 5 дают меньше нефти и на треть меньший ЧДД. При 250 мД одна скважина дренирует огромную площадь, скважины мешают друг другу (интерференция), обводняются одновременно, а каждая стоит 70 млн руб плюс 4 млн в год. Эталон БВ8 обходится тремя скважинами.

B → E: насос. В варианте B ЭЦН-250 перегружены (подача ≈ 430 м³/сут при оптимуме 250): пласт мог бы отдать больше. ЭЦН-800 поднимает дебит до 900 м³/сут, и при той же сетке КИН растёт с 22 до 27 %, ЧДД – на четверть. Это форсированный отбор жидкости – стандартный приём на высокопроницаемых обводнённых пластах. Он работает, только пока закачка держит давление.

СоветРецепт для БВ8

Сейсмика → 2–4 вертикальные добывающие в своде на крупных ЭЦН → 1–2 нагнетательные по краю нефтяной зоны с первого года → ежегодно подбирать насос под дебит, держать давление, отключать скважины с обводнённостью выше 97–98 %. ГРП не нужен (Глава 5: в пласте 250 мД он даёт +10–20 %).

10.3 Сами

Измените варианты: сдвиньте нагнетательные ближе к добывающим, поставьте ЭЦН-1250, добавьте отключение обводнённых.

const f = neft.field({ scenario: "bv8" });
for (const [x, y] of [[750, 1000], [1000, 1150], [1000, 800]]) f.drill({ x, y, pump: "800" });
for (const [x, y] of [[700, 1300], [700, 650]]) f.drill({ x, y, type: "inj", choke: 16 });
for (let year = 1; year <= 5; year++) {
  await f.runAll(1, { step: 60 });
  for (const w of f.sim.wells) if (w.type === "prod" && w.on && w.fw > 0.98) { f.stop(w); print(`год ${year}: остановлена ${w.name}`); }
}
const s = f.stats();
print(`КИН ${(100 * s.kin).toFixed(1)} %, ЧДД ${s.npv.toFixed(0)} млн руб, давление ${s.avgP.toFixed(0)} атм`);
show(neft.lines([{ name: "мой вариант", rows: f.rows }], { y: "oil_td", label: "нефть, т/сут" }));
return f.wellTable();

10.4 Вопросы

  1. Почему в варианте A давление у скважин падает до 20 атм, а не до нуля?
  2. В варианте E среднее давление ниже, чем в B. Хорошо это или плохо? Что сделать, чтобы его поднять?
  3. Сколько нагнетательных нужно на три добывающие с ЭЦН-800, чтобы давление не падало? Проверьте в живой ячейке.
