14  Разбор 5. Бобриковский: вязкая нефть

neft = {
  const m = await import(new URL("assets/js/neft.js", document.baseURI).href);
  await m.ready();
  return m;
}
core = neft.core()

Бобриковский горизонт (Татарстан, Башкортостан) – кварцевые песчаники врезанных долин, 420 мД, русла до 2000 мД, неглубоко (1240 м), дешёвая скважина (40 млн руб). Но нефть вязкая – 22 сП, вода 1,1 сП: соотношение вязкостей 20. Сложность ★★. Урок разбора: как вязкость ограничивает КИН и почему здесь работа идёт с огромными объёмами воды.

14.1 Опыт: та же залежь, разная нефть

Чтобы увидеть вклад именно вязкости, возьмём одну и ту же залежь и одну расстановку (4 добывающие на ЭЦН-400 вокруг нагнетательной, «обращённая пятиточка») и подменим вязкость нефти: 22 сП (как в игре), 5 и 1,5 сП. Расчёт – 5 лет.

viewof go15 = Inputs.button("▶ Рассчитать варианты")
Код вариантов (ядро игры) 
variants15 = {
  const mk = (mu) => () => {
    const f = neft.field({ scenario: "bb", pKNS: 150, mu_o: mu });
    for (const [x, y] of [[800, 1350], [800, 850], [1050, 1100], [550, 1100]]) f.drill({ x, y, pump: "400" });
    f.drill({ x: 800, y: 1100, type: "inj", choke: 24 });
    return f;
  };
  return [["μн = 22 сП (как в игре)", mk(22)], ["μн = 5 сП", mk(5)], ["μн = 1,5 сП", mk(1.5)]];
}
run15 = {
  if (!go15) { yield null; return; }
  for await (const st of neft.compare(variants15, 5, { step: 60 })) yield st;
}
neft.report(run15, { layer: "Sw", charts: ["oil_td", "kin", "wc", "money"], mapWidth: 300 })

Ожидаемые результаты (5 лет):

14.2 Разбор

  • Вязкость режет КИН. При той же закачке и тех же скважинах вязкая нефть даёт на 40 % меньше нефти. Причина – функция f_w (Глава 3): при \mu_o/\mu_w=20 вода в потоке преобладает уже при небольшой водонасыщенности, фронт размазан, и за ним остаётся много подвижной нефти, которая выходит только с огромными объёмами воды.
  • Обводнённость высокая с первого года во всех вариантах – это особенность расстановки: залежь тонкая (7 м), значительная часть скважин стоит в водонефтяной зоне, а нагнетательная в 250 м. Но при вязкой нефти обводнённость на 95–98 % – это обычный рабочий режим, а не повод останавливать скважину.
  • Экономика держится на дешевизне. Мелкая залежь, дешёвая скважина, дешёвая энергия подъёма (1240 м) – поэтому даже при 16 м³ жидкости на тонну нефти вариант прибылен.

14.3 Порог отключения на вязкой нефти

На БВ8 разумно отключать скважины при обводнённости 97–98 %. На бобриковском при таком правиле можно остановить весь фонд за пару лет – и потерять половину добычи. Посчитайте порог сами виджетом в Глава 7: скважина с дебитом жидкости 600 м³/сут, ЭЦН 60 кВт, цена 12 000 руб/т окупается до обводнённости ≈ 98,8 %.

// правило отключения: попробуйте порог 0.95, 0.98, 0.995
const thr = 0.95;
const f = neft.field({ scenario: "bb", pKNS: 170 });
for (const [x, y] of [[800, 1300], [800, 900], [1050, 1100], [600, 1100]]) f.drill({ x, y, pump: "630" });
f.drill({ x: 800, y: 1100, type: "inj", choke: 24 }); f.drill({ x: 1000, y: 1350, type: "inj", choke: 24 });
for (let y = 1; y <= 6; y++) {
  await f.runAll(1, { step: 60 });
  for (const w of f.sim.wells) if (w.type === "prod" && w.on && w.fw > thr) { f.stop(w); print(`год ${y}: остановлена ${w.name} (${(100 * w.fw).toFixed(1)} %)`); }
}
const s = f.stats();
print(`порог ${thr}: КИН ${(100 * s.kin).toFixed(1)} %, ЧДД ${s.npv.toFixed(0)} млн руб, работает добывающих: ${f.sim.wells.filter((w) => w.type === "prod" && w.on).length}`);

При пороге 95 % все четыре добывающие останавливаются уже после первых лет: КИН ≈ 15 % вместо ≈ 22 %. Без остановок ЧДД почти тот же, а нефти в полтора раза больше – и это пойдёт в оценку за КИН.

СоветРецепт для вязкой нефти
  • Сетка «две добывающие на одну нагнетательную» (так делает эталон): закачки нужно меньше, чем отбора жидкости.
  • Крупные ЭЦН – форсированный отбор жидкости; но следите за загрузкой и энергией.
  • Порог отключения – по расчёту рентабельности, не по привычным 95 %.
  • ГРП не нужен (420 мД), ОПЗ после ГДИС – да.

14.4 Вопросы

  1. Почему при вязкой нефти выгоднее схема «2 : 1», а не пятиточечная?
  2. Найдите в живой ячейке порог, дающий максимальный ЧДД.
  3. Какой КИН давал бы бобриковский при вязкости 1,4 сП, как у БВ8? Сравните с пределом вытеснения.
