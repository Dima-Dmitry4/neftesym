Когда в порах две жидкости, они мешают друг другу. Эта глава объясняет, почему вода прорывается к скважинам, почему вязкая нефть – беда и сколько нефти вода вообще может вытеснить. Здесь же – ответ на вопрос, почему на бобриковском горизонте обводнённость растёт сразу, а на БВ8 – постепенно.

3.1 Относительные фазовые проницаемости (ОФП)

Каждая фаза течёт по своей части пор. Её «доля» проницаемости – относительная фазовая проницаемость k_r\in[0,1]: эффективная проницаемость фазы равна k\cdot k_r. В игре ОФП линейные («поршневые»):

k_{rw}(S_w)=\frac{S_w-S_{wc}}{1-S_{wc}-S_{or}},\qquad k_{ro}(S_w)=\frac{1-S_{or}-S_w}{1-S_{wc}-S_{or}},

с ограничением в [0,1]. При S_w=S_{wc} течёт только нефть, при S_w=1-S_{or} – только вода, остаток нефти неподвижен. Реальные ОФП – кривые (модель Кори, k_r\propto s^n, n=2\ldots4); линейные проще и дают более резкий фронт.

3.2 Доля воды в потоке

Если в точке текут обе фазы под одним градиентом давления, доля воды в общем потоке – функция Бакли–Леверетта:

f_w(S_w)=\frac{k_{rw}/\mu_w}{k_{rw}/\mu_w+k_{ro}/\mu_o}=\frac{1}{1+\dfrac{k_{ro}}{k_{rw}}\dfrac{\mu_w}{\mu_o}} .

Обводнённость добывающей скважины в игре – это f_w в её ячейке (точнее, по ячейкам перфорации). Ключевой параметр – соотношение вязкостей M_0=\mu_o/\mu_w: чем вязче нефть, тем больше воды в потоке при той же насыщенности.

bl = {
  const r = { Swc: fl.Swc, Sor: fl.Sor, mu_o: fl.mu_o, mu_w: fl.mu_w }, pts = [];
  for (let s = r.Swc; s <= 1 - r.Sor + 1e-9; s += 0.0025) pts.push({ Sw: s, krw: core.krw(s, r), kro: core.kro(s, r), fw: core.fw(s, r) });
  // касательная из (Swc, 0) к кривой fw: насыщенность на фронте вытеснения Swf (построение Уэлджа)
  let best = pts[1];
  for (const p of pts.slice(1)) if (p.fw / (p.Sw - r.Swc) > best.fw / (best.Sw - r.Swc)) best = p;
  const Swf = best.Sw, fwf = best.fw, Sav = r.Swc + (Swf - r.Swc) / fwf;      // средняя Sw за фронтом при прорыве
  const Ed = (Sav - r.Swc) / (1 - r.Swc);                                     // вытеснение к моменту прорыва
  return { r, pts, Swf, fwf, Sav, Ed, PVbt: 1 / (fwf / (Swf - r.Swc)) };
}

Переключите объект с БВ8 на Бобриковский: соотношение вязкостей вырастает с 3 до 20, насыщенность на фронте падает, обводнённость сразу после прорыва подскакивает, а к моменту прорыва вытеснено заметно меньше нефти. Дальше нефть добывается долгим «промыванием» с высокой обводнённостью.

3.3 Задача Бакли–Леверетта

Представим одномерный пласт: с одного конца закачивается вода, с другого отбирается жидкость. Закон сохранения воды

\varphi\frac{\partial S_w}{\partial t}+\frac{u}{A}\frac{\partial f_w(S_w)}{\partial x}=0

говорит, что каждая насыщенность движется со скоростью, пропорциональной f_w'(S_w). Решение – ударный фронт: насыщенность скачком растёт от S_{wc} до S_{wf}, а за фронтом плавно увеличивается. S_{wf} находят касательной из точки (S_{wc},0) к кривой f_w – построение Уэлджа (пунктир на графике выше). Из него же:

  • фронт приходит к добывающей после закачки 1/f_w'(S_{wf}) поровых объёмов;
  • средняя насыщенность за фронтом \bar S_w = S_{wc}+(S_{wf}-S_{wc})/f_w(S_{wf}) – точка, где касательная пересекает f_w=1.

Проверим численно – той же явной схемой «против потока», что в ядре игры:

import numpy as np, matplotlib.pyplot as plt
from minisim import fw

Swc, Sor, mu_o, mu_w = 0.25, 0.28, 1.4, 0.45     # БВ8; попробуйте бобриковский: 0.18, 0.25, 22, 1.1
n = 200; dx = 1.0 / n                            # пласт длиной 1, 200 ячеек
S = np.full(n, Swc)
pv_injected, dt = 0.0, 0.05 * dx                 # шаг по условию Куранта (в долях порового объёма)

fig, ax = plt.subplots(figsize=(7, 3.6))
for target in [0.1, 0.2, 0.3]:                   # закачано поровых объёмов
    while pv_injected < target - 1e-12:
        f = fw(S, mu_o, mu_w, Swc, Sor)
        f_in = np.concatenate([[1.0], f[:-1]])   # вход: чистая вода, далее – из соседа слева (upwind)
        S += dt / dx * (f_in - f)
        pv_injected += dt
    ax.plot(np.linspace(0, 1, n), S, label=f"{target:.1f} PV")
ax.set_xlabel("x / L"); ax.set_ylabel("Sw"); ax.legend(title="закачано")
ax.set_title("Фронт вытеснения: численное решение")

Видно: фронт – крутая ступенька, но численно она «размазана» на несколько ячеек (численная диффузия). В игре на сетке 40 м фронт занимает 2–4 ячейки. При вязкой нефти ступенька ниже, а «хвост» за ней длиннее.

3.4 Что это значит для игры

Маловязкая нефть (БВ8, ЮВ1, ЮК10–11, ачимовка). Поршневое вытеснение, высокая насыщенность на фронте. До прорыва скважины работают почти без воды, после – обводнённость растёт быстро. Важно вовремя переводить обводнённые скважины под закачку или останавливать их.

Вязкая нефть (бобриковский, μн ≈ 22 сП). Вода прорывается рано и «языками», обводнённость сразу 70–80 %. Нефть добывается большими объёмами жидкости – нужны мощные ЭЦН, дешёвая подготовка жидкости и аккуратный расчёт рентабельности каждой скважины (Глава 14).

Высокая связанная вода (АВ1 «рябчик», ачимовка, S_{wc}=0{,}42). Мала подвижная нефть: предел вытеснения около 50 %. Высокий КИН здесь невозможен в принципе – оценка сравнивает с эталоном того же объекта.

УведомлениеУпрощения игры

Капиллярное давление и гравитация не моделируются, ОФП линейные, газа нет. Поэтому нет конусов подошвенной воды, а водонефтяная зона задаётся начальной S_w ячейки. Для учебной цели это допустимо: главные эффекты – прорыв, роль вязкости, предел вытеснения – воспроизводятся физично.

3.5 Вопросы и задания

  1. Почему при линейных ОФП и \mu_o=\mu_w фронт вытеснения – идеальный поршень?
  2. В виджете найдите \mu_н, при которой к прорыву вытесняется лишь половина подвижной нефти.
  3. В живой ячейке замените линейные ОФП на квадратичные (Кори, n=2) и сравните фронты.
