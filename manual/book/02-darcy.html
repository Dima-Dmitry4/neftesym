2  Закон Дарси и единицы игры

neft = {
  const m = await import(new URL("assets/js/neft.js", document.baseURI).href);
  await m.ready();
  return m;
}
core = neft.core()

Всё течение в пласте – и в жизни, и в игре – описывает один экспериментальный закон, открытый Анри Дарси в 1856 году при проектировании фонтанов Дижона. В этой главе выведем его «игровую» форму и константу CONV_K = 0.00864, которая встречается в ядре на каждом шагу.

2.1 Закон Дарси

Расход жидкости через пористую среду пропорционален площади, перепаду давления и проницаемости и обратно пропорционален вязкости и длине пути:

q=\frac{k\,A}{\mu}\,\frac{\Delta P}{L}.

В СИ: q – м³/с, k – м², A – м², \mu – Па·с, \Delta P – Па, L – м. Но в нефтянке так никто не считает: проницаемость в миллидарси, вязкость в сантипуазах, давление в атмосферах, дебит в м³/сут. Чтобы формула работала в этих единицах, нужен переводной коэффициент.

2.2 Вывод коэффициента K_Д

Подставим единицы игры в СИ:

Единица В СИ
1 мД 9{,}869\cdot10^{-16} м²
1 сП 10^{-3} Па·с
1 атм 101\,325 Па
1 сут 86\,400 с

q\left[\tfrac{м^3}{сут}\right]=86400\cdot\frac{9{,}869\cdot10^{-16}\,k\,A}{10^{-3}\,\mu}\cdot\frac{101325\,\Delta P}{L} =\underbrace{0{,}00864}_{K_Д}\cdot\frac{k\,A}{\mu}\,\frac{\Delta P}{L}. \tag{2.1}

Проверим живой ячейкой (первый запуск Python займёт 10–30 с):

mD, cP, atm, day = 9.869233e-16, 1e-3, 101325.0, 86400.0
K = day * mD * atm / cP
print(f"K_Д = {K:.5f} м³/сут·сП/(мД·м·атм)")

# поток между двумя ячейками игры: k = 100 мД, грань 40×10 м, путь 40 м, перепад 10 атм, нефть 5 сП
k, A, L, dP, mu = 100, 40 * 10, 40, 10, 5
print(f"q = {K * k * A / mu * dP / L:.1f} м³/сут")

2.3 Калькулятор Дарси

viewof dk = Inputs.range([0.01, 2000], {value: 100, label: "k, мД", transform: Math.log})
viewof dmu = Inputs.range([0.3, 50], {value: 5, step: 0.1, label: "μ, сП"})
viewof ddp = Inputs.range([1, 200], {value: 50, step: 1, label: "ΔP, атм"})
viewof dL = Inputs.range([10, 1000], {value: 200, step: 10, label: "L, м"})
viewof dA = Inputs.range([10, 20000], {value: 4000, step: 10, label: "A, м²"})
{
  const q = core.CONV_K * dk * dA / dmu * ddp / dL;
  return html`<div class="neft-kpi"><div><b>${q < 10 ? q.toFixed(2) : q.toFixed(0)} м³/сут</b><span>расход по Дарси</span></div>
  <div><b>${(q * 0.86).toFixed(q < 10 ? 2 : 0)} т/сут</b><span>если это нефть (ρ = 0,86)</span></div></div>`;
}

Попробуйте: БВ8 (250 мД, 1,4 сП) против ачимовки (0,07 мД, 1 сП) при тех же размерах. Разница в тысячи раз – вот почему на ачимовке нужны ГРП и горизонтальные скважины с МГРП, а на БВ8 хватает вертикальных.

2.4 Подвижность

Проницаемость и вязкость всегда входят парой k/\mu. Отношение \lambda = k_r/\mu называют подвижностью фазы (k_r – относительная фазовая проницаемость, см. Глава 3). При совместном течении нефти и воды суммарная (тотальная) подвижность

\lambda_t=\frac{k_{rw}}{\mu_w}+\frac{k_{ro}}{\mu_o},

и закон Дарси для смеси: q = K_Д\,k\,\lambda_t\,A\,\Delta P/L. Так он и записан в ядре игры: проводимость грани T = K_Д\,k_{harm}\,h\,\bar\lambda_t (Глава 4).

2.5 Плоскорадиальный приток к скважине

К вертикальной скважине жидкость сходится со всех сторон. Площадь, через которую она проходит, на расстоянии r – боковая поверхность цилиндра 2\pi r h. Подставив её в закон Дарси и проинтегрировав от радиуса скважины r_w до радиуса контура питания r_e, получим формулу Дюпюи:

q=\frac{2\pi\,K_Д\,k\,h}{\mu\,\ln(r_e/r_w)}\,(P_e-P_{wf}). \tag{2.2}

Величина J = q/(P_e - P_{wf}) – коэффициент продуктивности (м³/сут/атм). Обратите внимание на логарифм: давление теряется в основном у самой скважины – половина перепада срабатывает на первых метрах. Поэтому так важно состояние призабойной зоны (скин, Глава 5) и поэтому ГРП, создающий «длинный проводник» из скважины в пласт, так сильно увеличивает дебит.

viewof rre = Inputs.range([50, 1000], {value: 500, step: 10, label: "r_e, м"})
{
  const rw = 0.1, pts = [];
  for (let r = rw; r <= rre; r *= 1.04) pts.push({ r, P: 100 + (250 - 100) * Math.log(r / rw) / Math.log(rre / rw) });
  return neft.Plot.plot({ width: 640, height: 240, marginLeft: 50, x: { label: "расстояние от скважины r, м", grid: true }, y: { label: "P, атм", domain: [90, 260], grid: true },
    marks: [neft.Plot.line(pts, { x: "r", y: "P", stroke: neft.colors().s[1], strokeWidth: 2 }), neft.Plot.ruleX([10], { stroke: neft.colors().muted, strokeDasharray: "3,3" }),
            neft.Plot.text([[10, 105]], { text: () => `на 10 м уже ${(100 * Math.log(10 / rw) / Math.log(rre / rw)).toFixed(0)} % перепада`, dx: 6, textAnchor: "start" }),
            neft.Plot.tip(pts, neft.Plot.pointerX({ x: "r", y: "P", title: (d) => `r = ${d.r.toFixed(1)} м\nP = ${d.P.toFixed(1)} атм` }))] });
}

СоветДля разработчика

Держите единицы в одной системе внутри расчёта и переводите только на выводе – так сделано в ядре. Самая частая ошибка в самописных симуляторах – смешать сутки и секунды или дарси и миллидарси: результат «работает», но врёт в тысячу раз.
