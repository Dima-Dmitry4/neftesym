Прототипы расчётных модулей

Гидродинамическое моделирование фильтрации нефти в пористой среде: учебные приложения и игры для студентов. Каждый прототип — автономный HTML-файл на чистом JavaScript (Canvas 2D), работает прямо из файловой системы, без сети, сборки и внешних зависимостей.

Без внешних зависимостей Оффлайн Открывается двойным щелчком
Реестр прототипов — prototypes.js. Как добавить новый прототип — см. README.md. Проверка реестра: node tests/check-prototypes.js.
