# AGENTS.md – руководство для разработчиков и ИИ-агентов

Репозиторий посвящён одной игре – **«Нефтяша»**, учебному симулятору разработки нефтяного месторождения. Описание для людей – в
[README.md](README.md), модель, формулы и допущения – в [docs/MODEL.md](docs/MODEL.md).

## Структура

```
index.html              игра целиком: три скрипта
                          #sim-core    чистое ядро без DOM (геология, скважины, оборудование, экономика, сиды, эталоны, самотест)
                          #wasm-accel  Rust-ядро в base64 (ГЕНЕРИРУЕТСЯ rust/embed.mjs, вручную не править)
                          #app         интерфейс: Plotly, карты, графики, гид, отчёт, игровой цикл
vendor/                 Plotly (локальная копия)
rust/                   Cargo-проект: решатель давления, потоки, перенос, CFL; embed.mjs встраивает сборку в index.html
tests/selftest.js       node-харнесс самотеста (--wasm: через WebAssembly)
tools/                  load-core.js (загрузка ядра в Node), search-reference.js (поиск эталонов)
docs/MODEL.md           описание модели; docs/img – снимки экрана для README
manual/                 методичка на Quarto (HTML + PDF, сборка в manual/book хранится в репозитории); см. manual/README.md
```

## Правила

- **Одна игра – один HTML-файл.** Без CDN, без сети; всё нужное лежит в репозитории. Публикация – GitHub-подобные Pages из корня.
- **Ядро отделено от интерфейса.** В `#sim-core` нет обращений к DOM; в `#app` нет физики. Новое поведение расчёта добавляйте в ядро и
  покрывайте проверкой в `tests/selftest.js`-наборе (функции `*Tests()` внутри `#sim-core`).
- **Единицы:** давление атм, проницаемость мД, вязкость сП, дебит м³/сут, время сут, деньги руб (на экране млн руб). Нефть в тонны – только при выводе (ρ = 0,86 т/м³).
- **Язык:** интерфейс, комментарии и документация – по-русски. Тире в текстах игры – короткое «–», длинное «—» не используем.
- **Детерминизм:** объект однозначно задаётся группой пласта, сидом и размером сетки; не используйте `Math.random` в геологии и эталонах.
- **Эталоны:** `REF` (ряды для канонических объектов) и `POLICIES` (политики для сидов) в `#sim-core` пересчитываются при изменении физики или цен:
  `tools/search-reference.js` → перенести политику и ряды в `index.html` → проверить `node tests/selftest.js`.

## Команды

```bash
node tests/selftest.js                      # самотест (≈ 3–4 мин на JS)
node tests/selftest.js --wasm               # через WebAssembly (≈ 1 мин) + сверка с JS

cd rust
wasm-pack build --target web --release --no-pack
node embed.mjs                              # встроить сборку в ../index.html

python -m http.server 8765                  # локальный просмотр: http://localhost:8765/
```

Для изменения `index.html` без перезаписи всего файла используйте точечные правки; файл большой (≈ 500 КБ из-за встроенного WebAssembly).

## Перед коммитом

1. `node tests/selftest.js` и `node tests/selftest.js --wasm` – все проверки зелёные.
2. Если менялся `rust/src/lib.rs` – пересобрать и выполнить `node rust/embed.mjs`.
3. Если менялись цены, физика или формулы – обновить эталоны и таблицу эталонов в `docs/MODEL.md`, число проверок в README/docs.
4. Проверить игру в браузере: старт на двух объектах, бурение, год расчёта, отчёт.
