# ПЕБИ — симулятор двухфазной фильтрации на вороной-сетке (МКЭ)

Экспериментальное веб-приложение: вытеснение нефти водой в изолированном элементе пласта
с одной нагнетательной и одной добывающей скважиной. Расчет на неструктурированной
вороной-сетке с гексагонально-доминантными ячейками; давление — смешанным методом конечных
элементов RT0 (эквивалент двухточечной аппроксимации потоков на вороной-сетке),
насыщенность — неявным методом с встречной аппроксимацией потока.

Запуск: открыть `index.html` в браузере (работает с диска, сборка не требуется) либо
`node server.js 8124` и открыть `http://127.0.0.1:8124/`. Тесты: `node tests/run.js`
(53 проверки). Управление: слайдеры скважин (забойное давление или дебит) действуют
во время расчета; карта давления/насыщенности; графики дебитов, обводненности,
приемистости, давлений и накопленной добычи.

Документ описывает расчетную модель, алгоритм построения сетки, алгоритм решения,
обоснования принятых решений и соответствие формул коду. Нумерация формул сквозная;
для каждого блока указан файл реализации.

## 1. Физическая постановка и допущения

Расчетная область — прямоугольник Ω = [0, L_x] × [0, L_y] в плане, толщина пласта h.
Внешняя граница непроницаемая (нулевой поток). Внутри области две скважины,
заданные точками (x, y) с радиусом ствола r_w: нагнетательная и добывающая.
Каждая работает в одном из двух режимов: заданное забойное давление p_wf или
заданный поверхностный дебит (для нагнетательной — приемистость).

Принятые допущения:

1. Две фазы: вода (вытесняющая) и нефть (вытесняемая). Фазы несмешивающиеся.
2. Слабая сжимаемость обеих фаз и породы (коэффициенты c_w, c_o, c_r).
3. Нет капиллярных сил: p_w = p_o = p (одно давление).
4. Нет гравитации: слой горизонтальный, движение в плоскости.
5. Пласт однородный по проницаемости и пористости (скалярная k).
6. Температура постоянна; растворенный газ не учитывается (система «вода–нефть»,
   недонасыщенная модель без газовой фазы).

Следствие допущений 3–4: суммарная скорость фаз коллинеарна градиенту давления и
поток каждой фазы выражается через общий поток через дробный поток f_w (п. 2.2).

## 2. Математическая модель

Файл: `js/core/fluid.js`. Неизвестные — давление p(x, t) и водонасыщенность S_w(x, t);
S_o = 1 − S_w. Все формулы ниже записаны в объемных переменных: «поверхностным»
(приведенным к p_ref) объемам соответствует множитель B_α(p), «пластовым» — сам объем.

### 2.1 Законы сохранения

Массовый баланс воды в приведенных объемах:

> **(1)**  ∂/∂t [ φ·S_w / B_w(p) ] + ∇·( v_w / B_w(p) ) = q_ws

нефти:

> **(2)**  ∂/∂t [ φ·S_o / B_o(p) ] + ∇·( v_o / B_o(p) ) = q_os

где φ — пористость; B_α(p) — объемный коэффициент фазы α (пластовый объем на приведенный);
v_α — скорость фильтрации фазы [пласт. м³/(сут·м²)]; q_ws, q_os — источники в приведенных
объемах [привед. м³/(сут·м³)], отличные от нуля в ячейках скважин.

### 2.2 Закон Дарси и подвижности

> **(3)**  v_α = − (k·k_rα(S_w) / μ_α) · ∇p ≡ −λ_α(S_w)·k·∇p

где k — абсолютная проницаемость [мД]; k_rα — относительные фазовые проницаемости;
μ_α — вязкости [сП]; λ_α = k_rα/μ_α — подвижности [1/сП]. Полная подвижность и суммарная
скорость:

> **(4)**  λ_t = λ_w + λ_o,  v_t = v_w + v_o = −λ_t·k·∇p

При отсутствии капиллярных сил и гравитации фазовые скорости пропорциональны общему
потоку с долей f_w — дробным потоком (коэффициентом подвижности воды):

> **(5)**  v_w = f_w(S_w)·v_t,  f_w(S_w) = λ_w / (λ_w + λ_o)

В единицах п. 4.1 во всех формулах (3)–(5) присутствует переводной коэффициент C
из (13): v_t = −C·λ_t·k·∇p; ниже C опускается и всегда входит в трансмиссибилити (15)
и индекс скважины (18).

### 2.3 Относительные фазовые проницаемости (Кори)

Нормированная насыщенность:

> **(6)**  Ŝ = (S_w − S_wc) / (1 − S_wc − S_or)

Кори с показателями n_w, n_o и концевыми точками k_rw0, k_ro0:

> **(7)**  k_rw = k_rw0·Ŝ^nw,  k_ro = k_ro0·(1 − Ŝ)^no

При S_w ≤ S_wc вода неподвижна (k_rw = 0), при S_w ≥ 1 − S_or неподвижна нефть.

### 2.4 Сжимаемость

Объемные коэффициенты: величина 1/B_α линейна по давлению относительно p_ref:

> **(8)**  B_α(p) = 1 / (1 + c_α·(p − p_ref)),  B_α(p_ref) = 1

Поровый объем растет с давлением:

> **(9)**  Vp(p) = Vp_ref·(1 + c_r·(p − p_ref)),  Vp_ref = φ·A_i·h для ячейки i

где A_i — площадь ячейки. Общая сжимаемость системы (используется в уравнении давления):

> **(10)**  c_t = S_w·c_w + S_o·c_o + c_r

Важно: c_r учитывается один раз — либо в c_t уравнения давления (п. 4.2), либо через
Vp(p) в аккумуляции транспорта (п. 4.4). Двойной учет завысил бы упругоемкость.

## 3. Построение сетки

Файл: `js/core/mesh.js`. Результат — вороной-диаграмма множества точек (сайтов),
обрезанная прямоугольником области: каждая ячейка — выпуклый полигон, все ячейки
покрывают Ω без перекрытий.

### 3.1 Выбор типа сетки

Требования: неструктурированность, локальное сгущение к скважинам, простота построения
в браузере и корректная (консистентная) двухточечная аппроксимация потоков. Двухточечная
аппроксимация (ТПФА) консистентна только на K-ортогональных сетках — сетках, у которых
отрезок, соединяющий центры смежных ячеек, перпендикулярен общей грани [4]. Вороной-диаграмма
K-ортогональна по построению: каждая ее грань лежит на серединном перпендикуляре отрезка
между двумя сайтами. На таких сетках клеточно-центрированный ТПФА эквивалентен смешанному
МКЭ с элементами Raviart–Thomas нулевого порядка (RT0) — решение и потоки совпадают [3], [5],
при этом ТПФА дает M-матрицу (дискретный максимум-принцип, монотонность давления).
Альтернативы отклонены: ТПФА на прямоугольной сетке не дает сгущения к точке; МКЭ P1
на треугольниках требует восстановления потоков (нелокально-консервативен без
постобработки); MPFA/mimetic методы на общих полигонах существенно сложнее при тех же
результатах на вороной-сетке.

Дополнительное свойство: итерации Ллойда (перенос сайта в центроид своей ячейки) приводят
вороной-диаграмму к центроидальной (CVT), которая на равномерной плотности состоит
практически из правильных шестиугольников [6] — отсюда гексагональный вид сетки.

### 3.2 Генерация точек с управляемой плотностью

Плотность точек задается функцией локального шага:

> **(11)**  s(x) = s_min + (s_max − s_min)·g(d),  g = t²·(3 − 2t),  t = min(1, d / R_grad)

где d — расстояние от x до ближайшей скважины, R_grad — радиус зоны сгущения,
g — гладкое сглаживание (smoothstep). Точки размещаются в три приема.

1) Сайты скважин добавляются первыми и фиксируются (скважина всегда оказывается в центре
своей ячейки).

2) Точки вдоль границы: обход периметра с локальным шагом 0.9·s(x) (чтобы граничные ячейки
не были крупнее объемных при том же s). Для исключения вырожденных (коллинеарных)
треугольников каждая точка сдвигается внутрь на (0.3 + 0.7·ξ)·ε, ε = 1e-4·s_min, и вдоль
стороны на 0.2·(0.9·s)·(ξ − 0.5), т.е. не более чем на ±0.09·s; ξ — равномерное случайное
число.

3) Внутренние точки — переменный пуассоновский отбор (dart throwing) с пространственным
хэшем: кандидат c принимается, если для всех принятых точек p

> **(12)**  |c − p| ≥ ½·(ρ(c) + ρ(p)),  ρ(x) = k_ρ·s(x),  k_ρ = 0.45

коэффициент k_ρ < 1 компенсирует низкую плотность случайной упаковки относительно
гексагональной решетки (при равном минимальном расстоянии случайный отбор дает в разы
меньше точек, чем решетка). Для расстояния до сайтов скважин критерий усиливается:
|c − скважина| ≥ 0.9·s_min — это гарантирует r_e/r_w ≳ 5 (п. 5.1). Число попыток
ограничено (400 тыс.), останов при 30 тыс. подряд отклоненных кандидатов.

Затем выполняются 2 итерации Ллойда: каждый внутренний сайт переносится в центроид своего
полигона; сайты скважин и границы закреплены. Точки ближе 0.85·s_min к скважинам
не перемещаются. После Ллойда триангуляция Делоне и вороной-диаграмма перестраиваются.

Целевое число ячеек N_target задается пользователем (0.8–10 тыс.); параметр s_max
подбирается бинарным поиском (14 итераций) так, чтобы число точек совпало с целевым;
s_min и R_grad при этом фиксированы.

### 3.3 Топология

Строится по `voronoi.cellPolygon(i)` (корректно обрезанному прямоугольником):

- ячейка i: сайт x_i, площадь A_i (формула шнурования), поровый объем Vp_ref,i = φ·A_i·h;
- внутренняя грань между ячейками i и j: отрезок грани [a, b] и расстояние d_ij = |x_i − x_j|.
  Грань классифицируется геометрически: оба конца отрезка равнодальны от сайтов i и j
  (с точностью 1e-6·d_ij) — тогда отрезок лежит на серединном перпендикуляре и является
  гранью между i и j. Такой критерий корректен и для граней, обрезанных границей области
  (обрезка укорачивает отрезок вдоль его же прямой, эквидистантность концов сохраняется);
- граничные грани (на сторонах прямоугольника) хранятся отдельно с перпендикулярным
  расстоянием от сайта до прямой грани — они используются тестами для ГУ Дирихле;
  в рабочих расчетах поток через них нулевой (закрытая граница).

Проверкой контролируется: сумма A_i = L_x·L_y (с точностью 1e-9 — т.е. сетка без дыр
и перекрытий), связность графа соседства, K-ортогональность.

## 4. Дискретизация и алгоритм решения

Файлы: `js/core/pressure.js` (давление), `js/core/transport.js` (насыщенность),
`js/core/timestepper.js` (шаг), `js/core/engine.js` (состояние, баланс).

### 4.1 Единицы и переводной коэффициент

Внутренние единицы: длина — м, время — сут, давление — бар, проницаемость — мД,
вязкость — сП, дебиты — м³/сут. Пересчет закона Дарси из этих единиц:

> **(13)**  q [м³/сут] = C · k[мД] · A[м²] · Δp[бар] / ( μ[сП] · L[м] ),
>  C = 9.869e-16 · 1e5 / 1e-3 · 86400 = 8.527e-3

(9.869e-16 — мД в м²; 1e5 — бар в Па; 1e-3 — сП в Па·с; 86400 — сутки в секундах).

### 4.2 Уравнение давления

Применяется последовательная схема расщепления: на шаге Δt = t^{n+1} − t^n сначала решается
уравнение давления с подвижностями, замороженными на моменте n, затем — уравнение
транспорта с замороженными потоками (п. 4.4). Уравнение давления получается суммированием
(1) и (2) с приближением общей сжимаемости [1, гл. 8; 2, гл. 5]:

> **(14)**  Vp_i·c_t,i^n·(p_i^{n+1} − p_i^n)/Δt − Σ_f T_f·λ_t,f·(p_j^{n+1} − p_i^{n+1}) = Q_t,i

Здесь Vp_i = φ·A_i·h (при p_ref-масштабе; влияние c_r на Vp в накоплении давления входит
в c_t через слагаемое c_r); c_t,i — по (10) с насыщенностями момента n (это делает систему
линейной); Q_t — суммарный дебит скважин ячейки в пластовых объемах [пласт. м³/сут].

Трансмиссибилити грани f между ячейками i и j (только порода, подвижность вынесена):

> **(15)**  T_f = C·h·L_f / ( d_i/k_i + d_j/k_j )

На вороной-грани d_i = d_j = d_ij/2, где d_ij = |x_i − x_j| (перпендикулярное расстояние
от каждого сайта до грани равно половине расстояния между сайтами), поэтому для
однородной k:

> **(16)**  T_f = C·h·L_f·k / d_ij

Восстановленный поток через грань (используется и уравнением транспорта, и графиками):

> **(17)**  v_f = T_f·λ_t,f·(p_i − p_j),  λ_t,f = ½·(λ_t,i + λ_t,j)

Арифметическое осреднение λ_t сохраняет знакоопределенность матрицы (M-матрица, дискретный
максимум-принцип); немонотонность транспорта гасится upwind-схемой (п. 4.4).

Система (14) симметричная, положительно определенная (диагональ: Σ T_f·λ_t,f + Vp·c_t/Δt +
скважинные члены; внедиагональные: −T_f·λ_t,f), решается предобусловленным методом
сопряженных градиентов с неполным разложением Холецкого IC(0) (п. 4.6).

### 4.3 Скважины

Файл: `js/core/wells.js`. Модель Писмана: скважина — точечный источник в центре ячейки,
связывающий давление ячейки p_i с забойным давлением p_wf через индекс продуктивности:

> **(18)**  WI = 2π·C·k·h / ln(r_e/r_w),  r_e = 0.2·√A_i

> **(19)**  q_t = WI·λ_t(S_i)·(p_i − p_wf) — добывающая;
>            q_t = WI·λ_t(S_i)·(p_wf − p_i) — нагнетательная; в обоих случаях q_t ≥ 0
>            [пласт. м³/сут]

r_e — эквивалентный радиус ячейки; коэффициент 0.2 соответствует решению Писмана для
квадратной ячейки со стороной Δ (r_e = 0.2·Δ = 0.2·√(Δx·Δy)) и по согласованию переносится
на полигональные ячейки через √A [7], [8]. Допустимость требует r_e/r_w ≳ 5; конструкция
s_min = max(3 м, 27·r_w) дает r_e/r_w ≳ 4.5 (при r_w = 0.1 м — r_e/r_w ≈ 5–8); предупреждение
выдается при r_e/r_w < 4.5. Обоснование величины коэффициента — численное: решение
на однородной прямоугольной вороной-сетке (для которой 0.2·√A — точное определение
Писмана) совпадает с гексагональной в пределах 1.2% (тест T3).

Режимы:

- **Забойное давление** (нелинейный член, входящий в матрицу): в (14) добавляется
  A_ii += WI·λ_t, b_i += WI·λ_t·p_wf. После решения дебит вычисляется по (19).
- **Дебит** (правая часть): нагнетательная — задана приемистость q_ws^tgt (привед.):
  Q_t = q_ws^tgt·B_w(p_i^n); добывающая — задан дебит жидкости q_liq^tgt (привед.):
  Q_t = −q_liq^tgt / ( f_w/B_w + (1−f_w)/B_o )|_{S^n, p^n}. Пересчет по состоянию n
  сохраняет линейность системы.

Разделение дебита по фазам (для транспорта и графиков):

> **(20)**  q_ws = f_w(S_i^{n+1})·q_t / B_w(p_i^{n+1}),  q_os = (1 − f_w(S_i^{n+1}))·q_t / B_o(p_i^{n+1})

Нагнетательная закачивает только воду (q_ws = q_t/B_w). При режиме заданного дебита
фактическое забойное давление восстанавливается как p_wf = p_i^{n+1} ∓ q_t/(WI·λ_t).
Кросс-флоу исключен: знак потока фиксируется в начале шага; дебитная скважина
останавливается, если расчетный p_wf выходит за физические пределы (добывающая — ниже
0.5 бар, нагнетательная — выше 500 бар), ее вклад удаляется одновременно из матрицы
давления и из источников транспорта.

### 4.4 Уравнение транспорта насыщенности

После решения (14) потоки v_f по (17) фиксируются (замораживаются) на весь шаг, и решается
нелинейное уравнение воды (1) с дискретизацией по времени неявно (backward Euler).
Аккумуляция — в приведенных объемах, породный член входит через Vp(p) по (9):

> **(21)**  [ Vp_i(p_i^{n+1})·S_i^{n+1}/B_w(p_i^{n+1}) − Vp_i(p_i^n)·S_i^n/B_w(p_i^n) ] / Δt
>           + Σ_f (± F_f) = Q_ws,i,  Q_ws,i = Q_t,i^{наг}/B_w,i^{n+1}
>             + f_w(S_i^{n+1})·q_t,i^{доб}/B_w,i^{n+1}

Поточный член с одноточечным встречным приближением (upwind по направлению общего
потока v_f; при v_f > 0 поток идет из i в j, upwind-ячейка — i):

> **(22)**  F_f = v_f · f_w(S_up) / B_w(p_up),  up = i при v_f > 0, иначе j;
>           для баланса ячейки i член берется со знаком «+» (отток из i), для ячейки j —
>           со знаком «−»; если апстрим — j, то для i отток отрицателен (приток)

Upwind обязателен: центральная аппроксимация f_w порождает осцилляции на фронте [1, гл. 9].
Нефтяное уравнение (2) отдельно не решается: S_o = 1 − S_w, его баланс выполняется с
точностью O(c·Δp_шага) как разность суммарного (14) и водного (21) балансов.

Система решается методом Ньютона. Невязка ячейки:

> **(23)**  R_i(S) = [ Vp_i(p^{n+1})·S_i/B_w,i^{n+1} − Vp_i(p^n)·S_i^n/B_w,i^n ] / Δt
>           + Σ_f ± v_f·f_w(S_up)/B_w_up − Q_t,i^{наг}/B_w,i^{n+1}
>           + f_w(S_i)·q_t,i^{доб}/B_w,i^{n+1}

(знак поточного слагаемого — как в (22); нагнетательная входит константой, не зависящей
от S; добывающая — через f_w(S_i), что делает ее источником нелинейности). Якобиан:

> **(24)**  ∂R_i/∂S_i = Vp_i(p^{n+1}) / (Δt·B_w,i^{n+1}) + Σ_{f: up=i} |v_f|·f'_w(S_i)/B_w,i
>           + [добывающая] q_t·f'_w(S_i)/B_w,i
> **(25)**  ∂R_i/∂S_up = ± v_f·f'_w(S_up)/B_w_up   (по одному входу на грань)

где f'_w — аналитическая производная (5) по S_w. Диагональный вклад грани положителен
при обоих направлениях потока (модуль |v_f|), внедиагональный берется со знаком по (25).
Система несимметричная, с диагональным преобладанием на принимаемых шагах (контроль (27)
дает |v_f|·f'_w·Δt/Vp ≲ 0.2·f'_w < 1), решается BiCGStab с ILU(0) (п. 4.6). Сходимость
Ньютона: ‖R‖_∞ = max_i |R_i|·Δt/Vp_i ≤ 1e-6, не более 8 итераций.

Ограничения на насыщенность: пробные точки Ньютона клампируются в

> **(26)**  lo = min(S_wc, min_i S_i^n) − 5e-3,  hi = max(1 − 1e-9, max_i S_i^n)

Нижняя граница учитывает физику сжимаемости: в ячейке без водного притока рост давления
требует dS_w = −S_w·(c_w + c_r)·dp (вода сжимается, а поровый объем растет), поэтому S
может опускаться чуть ниже S_wc; верхняя граница открыта до 1, поскольку за фронтом
обездвиженная (k_ro = 0) нефть при росте давления сжимается и S слегка превышает 1 − S_or
(жесткая граница 1 − S_or создавала бы неустранимую невязку). Выход за диапазон —
O((c_w + c_r)·Δp) снизу и O((c_o + c_r)·Δp) сверху, ~1e-3 — на потоки не влияет
(ОФП клампируются по (6)).

Линейный поиск: шаг Ньютона δS умножается на λ = 1, ½, ¼, … (до 1e-4); пробная точка
клампируется в (26); итерация принимается, если ‖R‖ не выросла (допуск ×1.001). Это
гарантирует монотонность и отсутствие осцилляций насыщенности (T7).

«Пол» невязки. У ячеек, зажатых границей (26) при продолжающемся притоке/оттоке,
остаток ‖R‖_∞ = O(v·c_w·Δp_соседа·Δt/Vp) неустраним никаким выбором S — это следствие
последовательного расщепления: транспорт взвешивает потоки по B_w апстрим-ячейки, а
уравнение давления — нет. Такой остаток принимается как сходящийся, если норма ≤ 1e-2 и
худшая ячейка лежит на границе (26); в основном цикле дополнительно требуется, чтобы
норма перестала убывать (‖R‖ ≥ 0.7·‖R_prev‖) и было сделано не менее 2 итераций; в ветке
отказа линейного поиска достаточно первых двух условий. Шаги с принятым «полом» не
ускоряют время (рост Δt блокируется), их вклад в дисбаланс фиксируется в диагностике.

Внешний цикл: после транспорта давление пересобирается с подвижностями от S^{n+1} и
решается заново; цикл до ‖S^{k+1} − S^k‖_∞ < 1e-3, не более 4 итераций. Это снимает
рассогласование подвижностей (потоки, вычисленные по S^n, не соответствуют S^{n+1}).

### 4.5 Адаптивный шаг по времени

Файл: `js/core/timestepper.js`. Попытка шага с Δt: управление скважин читается из
интерфейса, фиксируются решения о течении (п. 4.3), выполняются п. 4.2 → 4.4. Шаг
принимается, если Ньютон сошелся и

> **(27)**  max_i |S_i^{n+1} − S_i^n| ≤ 0.2

(ограничение по давлению отключено: вблизи скважин с заданным p_wf давление
квазистационарно привязано к забойному и меняется скачком при любом Δt — это свойство
решения, а не ошибка). После успеха Δt ← min(1.3·Δt, 60 сут); если шаг принят через «пол» —
рост Δt не выполняется. При отказе (не-сходимость Ньютона
или нарушение (27)) Δt делится пополам и попытка повторяется (до 30 делений), при
Δt < 0.001 сут расчет останавливается с сообщением. Типичный прогресс: старт с
Δt = 0.05 сут (заполнение прискважинных ячеек), выход на 10–60 сут (поздняя стадия).
Типичная стоимость шага: 40–60 мс на 3000 ячеек.

### 4.6 Линейные решатели

Файл: `js/core/sparse.js`. Матрицы хранятся в CSR с фиксированным шаблоном (диагональ +
соседи по граням), собираются в предвыделенные массивы без аллокаций на шаге.

- **Давление** — PCG (метод сопряженных градиентов) с предобуславливателем IC(0):
  неполное разложение Холецкого A ≈ L·Lᵀ без заполнения вне шаблона нижнего треугольника.
  Критерий: ‖r‖₂/‖b‖₂ ≤ 1e-10. Сходимость 10–90 итераций (растет с Δt).
- **Транспорт** — BiCGStab [9] с ILU(0) [10] (разложение в форме Саада: L с единичной
  диагональю, U — верхний треугольник, факторизация на копии массива значений).
  Критерий: относительная невязка ≤ 1e-9, не более 80 итераций.

Оба решателя покрыты тестом T2 на случайных SPD- и диагонально-доминантных системах.

### 4.7 Материальный баланс

Для контроля на каждом шаге вычисляются запасы в приведенных объемах

> **(28)**  WIP = Σ_i Vp_i(p_i)·S_w,i / B_w(p_i),  OIP = Σ_i Vp_i(p_i)·(1 − S_w,i)/B_o(p_i)

и невязка воды

> **(29)**  imb_w = (WIP^{n+1} − WIP^n)/Δt − (Q_ws^{всего} − Q_ws^{добыто})

При сходимости Ньютона (23) выполняется поточечно, поэтому imb_w ≈ 0 (в тестах ≤ 1e-8
от закачки; в приложении — отображается в статус-баре). Дисбаланс нефти — осмыслен
только вместе с (14): сумма фазовых накоплений согласована с давлением с точностью
O(c·Δp_шага) (тест T5 проверяет полный баланс и наклон среднего давления:

> **(30)**  dp̄/dt = Q_ws / (Vp_Σ·c_t),  p̄ = Σ Vp_ref,i·p_i / Σ Vp_ref,i
>           (вес — референсный поровый объем)

— закрытая система с постоянной закачкой; совпадение в пределах 0.6%).

## 5. Обоснование выбора схемы решения

1. **Вороной-сетка + ТПФА (≡ RT0)**. Альтернативы: прямоугольная сетка (не сгущается
   к точечным скважинам без локальных уточнений и висячих узлов — hanging nodes), МКЭ P1 на
   треугольниках (нелокально-консервативен, нужны постпроцедуры восстановления потока),
   MPFA/mimetic (консистентны на произвольных полигонах, но в 3–5 раз дороже и сложнее).
   Вороной-диаграмма дает K-ортогональность «бесплатно»: ТПФА на ней консистентен и
   монотонен [4], совпадает с RT0 [3], [5], а генерация сводится к триангуляции Делоне
   готовой библиотекой.
2. **Сгущение отбором точек + Ллойд**. Прямые структурированные сгущения (по логарифму
   радиуса вокруг скважины) дают анизотропные ячейки и требуют сшивки с фоновой сеткой.
   Отбор точек по (11)–(12) с последующей релаксацией просто, устойчив и управляется одной
   функцией плотности; детерминизм обеспечивает фиксированное зерно ГПСЧ (mulberry32).
3. **Последовательная схема (давление → транспорт) вместо полностью неявной**. Полностью
   неявная схема требует одновременного Ньютона по (p, S) с якобианом 2n×2n; при
   отсутствии капиллярных сил последовательная схема с внешним циклом дает практически
   ту же устойчивость при вдвое меньших системах и является стандартом де-факто [1, гл. 10],
   [2]. Плата — O(c·Δp_шага) рассогласование, контролируемое адаптивным шагом.
4. **Неявный транспорт**. Явный транспорт ограничен условием КФЛ Δt ≤ Vp/(v·f'_w) — у
   скважин (ячейки ~3 м, скорости ~м/сут) это доли суток, неприемлемо для интерактивного
   режима. Неявная схема безусловно устойчива; диффузия фронта контролируется (27)
   (эффективное число Куранта ≤ ~0.2 по насыщенности).
5. **PCG+IC(0) и BiCGStab+ILU(0)**. Матрица давления SPD → сопряженные градиенты
   оптимальны; предобуславливание необходимо (число обусловленности растет при больших
   Δt). Матрица транспорта несимметрична (upwind) → BiCGStab. Прямые методы (Холецкий)
   на 10 тыс. ячеек в JS проигрывают по памяти и времени.
6. **Клеточно-центрированные неизвестные** (давление и насыщенность в центрах ячеек, а не
   в узлах): естественны для ТПФА, локально-консервативны, напрямую отображаются на
   заливку полигональной карты.

## 6. Ограничения модели

1. Последовательное расщепление: рассогласование фазовых и суммарного балансов
   O(c·Δp_шага) (тест T5: ≤ 1% по полному балансу).
2. «Пол» невязки у граничных ячеек (п. 4.4): вклад в дисбаланс ≤ 1e-2·Vp/Δt на ячейку,
   отображается в статус-баре; на физику решения в протестированных сценариях не влияет.
3. Выход S за [S_wc, 1−S_or] на ~1e-3 (п. 4.4) — артефакт сжимаемости в расщепленной
   схеме, на потоки не влияет.
4. Однородный пласт; анизотропия сделала бы ТПФА неконсистентным (нужны MPFA/mimetic
   или диагональная k в главных осях с K-ортогональной сеткой).
5. Точность модели скважины ограничена условием r_e/r_w ≳ 5 и допущением изотропии.
