## 1. Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Физика | Вода/нефть, слабая сжимаемость (c_w, c_o, c_r), без капиллярных сил и гравитации (горизонтальный слой) |
| Дискретизация | Смешанный МКЭ RT0 ≡ двухточечные потоки (ТПФА) на вороной-сетке (K-ортогональной); клеточно-центрированная SPD-система |
| Транспорт | Последовательная неявная схема (SEQ): неявное давление → неявная насыщенность (upwind, Ньютон) |
| Сетка | Вороной от градуированных точек (гексагонально-доминантный), уплотнение к скважинам |
| Стек | Чистый JS, обычные `<script>`, офлайн с `file://`; vendor: d3-delaunay 6.0.4 (ISC), uPlot 1.6.32 (MIT); sparse-решатель собственный (CSR + PCG + BiCGStab + ILU(0)) |
| Единицы | длина м, время сут, давление бар, проницаемость мД, вязкость сП, дебиты м³/сут (поверхностные ↔ пластовые через объемный коэффициент B(p)) |
| Тесты | Node-тесты численного ядра; браузерная проверка встроенным браузером + visual-judge субагент |

## 2. Физическая модель

Переменные: клеточное давление `p` [бар], водонасыщенность `S_w`; `S_o = 1 − S_w`.

Закрытая внешняя граница (нулевой поток). Область — прямоугольник `Lx × Ly`, толщина слоя `h`.

**Свойства флюидов:**
- ОФП Кори по нормированной `Ŝ = (S_w − S_wc)/(1 − S_or − S_wc)`: `k_rw = k_rw0 Ŝ^nw`, `k_ro = k_ro0 (1−Ŝ)^no`.
- Подвижности: `λ_w = k_rw/μ_w`, `λ_o = k_ro/μ_o`, полная `λ_t = λ_w + λ_o` (в 1/(сП)).
- Объемные коэффициенты: `B_α(p) = 1/(1 + c_α (p − p_ref))` (поверхн. м³ ↔ пласт. м³).
- Дробный поток (без капиллярности/гравитации): `f_w(S_w) = λ_w/(λ_w + λ_o)`.

**Последовательная схема (шаг n → n+1, dt)** — уравнение давления в пластовых объемах, транспорт — в референсных (p_ref; B(p_ref)=1; «поверхностные» = референсные):

1. Давление (неявно, подвижности с n; **подвижность входит один раз**):
   `Vp_i·c_t,i^n·(p_i^{n+1} − p_i^n)/dt + Σ_f T_f·λ_t,f·(p_i^{n+1} − p_j^{n+1}) = Q_t,i`
   где `Vp_i = φ A_i h`, `c_t = S_w^n c_w + S_o^n c_o + c_r`, `T_f = C·L_f/(d_i/k_i + d_j/k_j)` — только порода (гармоническое среднее k), `λ_t,f = (λ_t,i + λ_t,j)/2`, `Q_t` — пластовый дебит источников [пласт. м³/сут]. SPD → **PCG+IC(0)**.
2. Потоки фиксируются: `v_f = T_f·λ_t,f·(p_i^{n+1} − p_j^{n+1})` [пласт. м³/сут].
3. Насыщенность (неявно, upwind по общему потоку):
   `Vp_i(p^{n+1})·[S_i^{n+1}/B_w^{n+1}] − Vp_i(p^n)·[S_i^n/B_w^n]` /dt + Σ_f F_f^{out,i} = Q_ws,i
   — аккумулирует породный член через `Vp(p) = Vp_ref·(1+c_r Δp)` (c_r НЕ добавлять отдельно — иначе двойной счет). `F_f^{out,i} = v_f·f_w(S_up)/B_w(up-ячейки)`. Ньютон: нелинейность через `f_w(S_up)` на каждом грани и член притока добывающей; residual `max_i|R_i|·dt/Vp_i ≤ 1e-6`, ≤ 25 итераций, line-search делением пополам с отбраковкой S вне [S_wc, 1−S_or]. Матрица несимметричная → BiCGStab+ILU(0).
4. Дебиты (референсные): добывающая `q_ws = f_w(S_i^{n+1})·q_t/B_w`, `q_os = (1−f_w)·q_t/B_o`; нагнетательная `q_ws = q_t/B_w(p_cell^{n+1})`. В транспорт и графики идет **ровно тот q_t, что участвует в уравнении давления** (для BHP — вычисленный из решения с λ_t^n; для дебитного режима — заданный лагом).

Сумма фазовых балансов согласована с давлением с точностью O(c·Δp_шага) (стандартное приближение общей сжимаемости); баланс каждой фазы в транспорте выполняется точно (до толеранса Ньютона).

**Материальный баланс** контролируется каждый шаг (расхождение аккумуляции и источников по обеим фазам, в референсных объемах), лог в статус-бар и историю.

## 3. Сетка

- Детерминизм: seeded PRNG (mulberry32), seed — явный параметр (тесты T8 фиксируют).
- Точки: пуассоновское семплирование (dart throwing с пространственным индексом) по функции плотности: `s(x) = s_min + (s_max − s_min)·g(d)`, `d` — расстояние до ближайшей скважины, `g` — гладкое насыщение на радиусе `R_grad ≈ 130 м`; `s_min = max(3 м, 27·r_w)` (при `r_e ≈ 0.186·s` на гекс-сетке обеспечивает `r_e/r_w ≳ 5` — условие применимости Писмана; предупреждение при нарушении), `s_max` — из бисекции по целевому числу ячеек (слайдер 1–10 тыс., `s_min` и `R_grad` фиксированы). Дополнительно точки вдоль границы прямоугольника.
- Вороной: `d3-delaunay`; 2 итерации Ллойда (закреплены точки скважин И граничные точки; граничные могут скользить по своей стороне) — релаксация выравнивает сетку к гексагональной.
- Топология: ячейки {центр = сайт, площадь, Vp}, грани {i, j, длина L_f, d_i, d_j}; грани извлекаются из halfedges Делоне (отрезок между циркумцентрами смежных треугольников), клиппинг в прямоугольник; нулевые/вырожденные грани отбрасываются, пары дедуплицируются; граф соседей — из граней (не из смежности Делоне). Грани на границе домена — отдельный список (рендер + тестовые ГУ Дирихле; для них `d_i` = перпендикулярное расстояние сайт→отрезок).
- Трансмиссибилити: `T_f = C·L_f / (d_i/k_i + d_j/k_j)` — только порода; подвижность в потоке один раз (`v_f = T_f·λ_t,f·Δp`). `C = 8.527e-3` (мД, м, бар, сП → м³/сут). Для вороной-грани `d_i = d_j = |x_i − x_j|/2`; K-ортогональность вороной-сетки обеспечивает консистентность схемы (RT0-эквивалент).
- Целевое число ячеек: слайдер 1–10 тыс. (по умолчанию ~3–4 тыс.).

## 4. Скважины (Писман)

- `WI = C·2π·k·h / ln(r_e/r_w)`, `r_e = 0.2·√A` (конвенция MRST), `q_t = WI·λ_t·(p_cell − p_wf)` [пласт. м³/сут]; калибруется радиальным тестом (T3).
- Режимы независимо для каждой скважины (переключатель + слайдер, действует со следующего шага):
  - **BHP**: `p_wf` слайдером; член в матрице давления `diag += WI·λ_t`, `rhs += WI·λ_t·p_wf`.
  - **Дебит**: добывающая — поверхностный дебит жидкости `q_liq`; нагнетательная — поверхностная приемистость `q_ws`. Пересчет в пластовый: `q_t = q_liq/(f_w/B_w + f_o/B_o)` (по состоянию n, лаг), `q_t = q_ws·B_w`.
- Без кросс-флоу: знак q_t фиксируется в начале шага (по состоянию n); если скважина «не течет», ее вклад удаляется одновременно из матрицы давления И из источников транспорта (решение клампа — часть шага, внутри Ньютона не меняется), событие логируется.
- Подвижность нагнетательной: полная λ_t (стандарт; исключает λ_w(S_wc)=0); добывающей — по фазам через f_w.
- Фактический BHP при дебитном режиме вычисляется из решения и выводится на график (и наоборот).

## 5. Управление шагом по времени

- Адаптивный dt: `max|ΔS| ≤ 0.2`, `max|Δp| ≤ 5 бар`; рост ×1.3; несходимость Ньютона ИЛИ нарушенные лимиты после сходящегося шага → откат и повтор с dt/2; при dt_min → пауза + сообщение; `dt ∈ [0.01, 60] сут`.
- История (для графиков): t, dt, q_o_s, q_w_s, обводненность, приемистость, p_wf факт обеих, среднее пластовое, накопленная нефть/вода, дисбаланс.
- Движок детерминирован (фиксированные параметры → фиксированная траектория) — регрессионный тест T8.

## 7. UI (одностраничный, темная тема, русский язык)

- **Слева (сайдбар)**: карточки скважин (нагнетательная/добывающая): режим BHP↔дебит, слайдер, факт. значения; пуск/пауза/шаг/сброс, скорость; параметры сетки (целевое число ячеек + «Перестроить»); аккордеон свойств пласта/флюидов (изменение → сброс расчета).
- **Центр**: карта на canvas: переключатель «Давление / Насыщенность»; заливка ячеек, легенда с шкалой, скважины (маркеры, подписи, факт. режим), клик — выбор скважины, hover — tooltip ячейки (p, S_w, Vp). Контур сетки — опционально.
- **Снизу**: графики uPlot: (1) дебиты нефти и воды добывающей; (2) приемистость и индекс приемистости `II = q_ws/(p_wf − p̄)`; (3) забойные давления (факт) + среднее пластовое; (4) накопленная добыча нефти + обводненность. Перестроение сетки сбрасывает расчет.
- **Статус-бар**: время (сут/год), номер шага, dt, число ячеек, дисбаланс, время шага (мс).
- Слайдеры скважин читаются движком на каждом шаге — управление «на лету». NaN/сходимость → пауза + сообщение.

## 9. Тесты (Node, `node tests/run.js`)

| # | Тест | Критерий |
|---|---|---|
| T1 | Сетка: сумма площадей = Lx·Ly; связность графа соседства; K-ортогональность: концы сегмента грани равнодальны от обоих сайтов, нормаль ∥ линии центров (только внутренние грани); градация размеров (у скважин < s_max/3) | ≤ 1e-9 отн. |
| T2 | Решатели: PCG+IC(0) (случайная SPD), BiCGStab+ILU(0) (случайная несимметричная с диаг. преобладанием) с известным решением | ‖err‖∞ ≤ 1e-8 |
| T3 | Стационарный радиальный приток: 1 скважина (BHP), внешний прямоугольник Дирихле (тестовое ГУ), однофазный несжимаемый предел; эталон — метод изображений (знакочередующаяся решетка, суммирование до сходимости); проверка калибровки r_e = 0.2·√A и сходимости q при сгущении | q vs эталон в пределах 8% |
| T4 | Стационарный линейный поток между двумя скважинами (обе дебитные) в узкой полосе: профиль давления vs аналитика | ≤ 2% на средних ячейках |
| T5 | Материальный баланс с сжимаемостью: закрытая система + закачка постоянным дебитом; фазовые дисбалансы по шагам (норма `max_i|R_i|·dt/Vp_i`, тестовый Ньютон-допуск 1e-9); наклон `dp̄/dt` (Vp-взвешенное p̄) vs `q/(Vp·c_t)` | дисбаланс ≤ 1e-8 отн.; наклон в 1% |
| T6a | Бакли–Леверетт (c=0): 1D-цепочка гексагональных ячеек (ширина 1 ячейка), обе скважины дебитные (известный постоянный u); фронт `S_f` (из `f_w'(S_f) = f_w(S_f)/(S_f−S_wc)`) и положение `x_f = (W_i/(Aφ))·f_w'(S_f)`; обводненность vs построение Вельге — в координатах закачанных поровых объемов | фронт ±5%; f_w-кривая L1 ≤ 0.05 |
| T6b | 2D-полоса (слабый тест): симметрия S относительно осевой линии, монотонность фронта по централине, обводненность между 1D-кривой и 1D-кривой со сдвигом на коэффициент охвата | качественные критерии |
| T7 | Монотонность: `S_wc ≤ S ≤ 1−S_or` во всех ячейках на всех шагах T6 (обеспечивается line-search с границами) | без исключений |
| T8 | Регрессия: детерминированный прогон сценария по умолчанию (seeded mesh, seed в параметрах), контрольные числа (t, q, p̄) в снапшоте | совпадение 1e-10 |

## 10. Процесс контроля качества

1. План → критик-субагент → правки (этот документ).
2. Реализация: ядро + тесты Node (каждый модуль → его тест) → UI.
3. Ревью кода субагентами: (а) численное ядро, (б) UI/интеграция; исправления.
4. Браузер: открытие `index.html` во встроенном браузере, консоль без ошибок, интеракции (пуск/пауза, слайдеры, переключение карт, перестроение сетки), скриншоты → visual-judge субагент → исправления → повторная проверка.
5. README.

## 11. Риски и запасные варианты

- **Извлечение граней вороной с клиппингом** — самая деликатная часть; покрывается T1; запасной вариант — построение граней обходом `cellPolygon` с классификацией вершин.
- **BiCGStab может плохо сходиться при резком фронте** → ILU(0) + ограничение dt; при неудаче — переход на Picard (линейный upwind с лагом f_w').
- **Калибровка r_e для полигональных ячеек** — допуск 8% в T3; если не проходит — численная калибровка коэффициента на сетке (процедура Писмана).
- **file:// + UMD** — подтверждено исследованием; при проблемах — мини-сервер `npx http-server` для браузерной проверки.
- **Производительность рендера** — offscreen-буфер карты, redraw по dirty-флагу, децимация точек графиков.
